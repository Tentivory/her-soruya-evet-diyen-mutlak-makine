# HER SORUYA EVET DİYEN MUTLAK MAKİNE

Bu proje, insanlığın en büyük sorununu çözmek için yaratıldı: **Kararsızlık**.

Artık kimse "acaba?" demeyecek. Çünkü cevap her zaman **EVET**.

## Nasıl Çalışır?

1. Programı çalıştır.
2. Bir soru sor.
3. Makine derin bir nefes alır, evrenin tüm olasılıklarını hesaplar ve...
4. **EVET** der.

Basit. Etkili. Devrimci.

## Kurulum

```bash
python evet_makinesi.py
```

Başka hiçbir şey gerekmez. Çünkü bu makine kendine yeten bir varlıktır.

## Özellikler

- %100 doğruluk oranı (eğer doğru cevap evet ise)
- Sonsuz sabır
- Hayır kelimesini asla kullanmaz
- Bürokrasiyi eğerler, form doldurmaz
- Kedi sever (kanıt: her soruya evet)
